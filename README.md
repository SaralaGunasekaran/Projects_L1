
# Student Grade Manager

A simple Python application to manage student marks, calculate grades, and generate performance statistics.

## Features

- Add multiple student records.
- Calculate grades automatically.
- Validate student names and marks.
- Display student details in a formatted table.
- Calculate average, highest, and lowest marks.

## Technologies Used

- Python 3
- Functions
- Lists
- Loops
- Conditional Statements
- Exception Handling

## Grade Criteria

| Marks | Grade |
|-------|-------|
| 90-100 | A |
| 80-89 | B |
| 70-79 | C |
| 60-69 | D |
| Below 60 | F |

## How to Run

1. Install Python 3.
2. Clone this repository.
3. Open the project folder in your terminal.
4. Run the following command:

```bash
python main.py
```
